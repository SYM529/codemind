CodeMind 一条请求的完整旅程
锚点：用户在代码工作台粘贴一段代码 → 点「生成注释」→ 结果流式上屏。数字 = 数据流动顺序，也是建议的读码顺序。
前端 · Vue3（client/）
【1】views/Home.vue 粘贴代码、点生成 → api/index.js 发起 SSE 流式请求 POST /api/ai/generate-comments/stream
↓
请求入口 · FastAPI（server_py/）
【2】routes/ai.py 第一站：JWT 鉴权（401）→ 每日额度（429）→ 代码长度限制（413）→ 转发给服务层
【3】services/code_analyzer.py 代码结构分析：Python 用 AST，JS/Java 用正则，识别函数、类、行号
↓
【4】services/cache_service.py · 语义缓存（分叉点）
请求签名做向量相似度匹配：相似度 ≥ 0.98 命中 → 直接复用历史结果，跳过 5-8 全部 AI 调用；未命中才继续往下。
虚线捷径：缓存命中 → 直接到【8】记录本次为 cache 来源。
↓ 未命中
核心生成链路 · 服务层
【5】services/rag_service.py RAG 混合检索：BM25 + 向量召回加权融合（0.65/0.35）→ 词面重排 → build_context 拼成「片段N」注入文本
【6】services/ai_comment_service.py LangChain 组装 Prompt（代码+结构分析+RAG 上下文）→ DeepSeek SSE 逐 token 流式生成
【7】models.py JSON 清洗 + Pydantic 结构化校验：容忍模型输出 Markdown 围栏/顶层数组
↓
落库与观测 · 数据层
【8】evaluation_service.py 算函数覆盖率/行号有效率 → usage_service.py 记真实 Token 与成本 → generation_history_service.py 存历史（都按 user_id 隔离）
【9】database.py MySQL/SQLite 双驱动：生产 MySQL 8，本地开发零配置回退 SQLite（环境变量 DB_DRIVER 切换）
↓
回到前端
DebugPanel 流式展示 + RAG 命中/缓存状态/成本可视化；历史、用量、质量评估和管理员看板（views/History.vue、Admin.vue）均可查。
推荐读码顺序（不要按文件列表啃，按这条链走两遍）
① README.md 全文——它就是你的地图，架构图、流程图、已知局限全在里面
② main.py + config.py——入口和配置：启动时建表、读环境变量、挂路由
③ routes/ai.py——请求进来的第一站，看校验和转发
④ ai_comment_service.py——整条链的心脏，看 Prompt 怎么拼、流式怎么发
⑤ rag_service.py + embedding_service.py——RAG 本体（刚才讲过）
⑥ cache_service.py → database.py → models.py——缓存与数据模型
⑦ client/src/views/Home.vue + api/index.js——前端怎么调、SSE 怎么收
⑧ docs/TROUBLESHOOTING.md——真实踩过的坑，面试时是现成素材
然后：本地把服务跑起来（docker compose up 或直接 python main.py），打断点/加 print，实际发一次请求，观察每层收到什么、输出什么。
自测清单：能答上来 = 真懂了（面试就问这些）
▸ 缓存命中时，哪些步骤被跳过？答：RAG、DeepSeek 调用、质量评估，只记录一条 cache 来源的用量
▸ RAG 检索失败会发生什么？答：优雅降级——返回空上下文继续生成，但记日志，不打断用户
▸ 为什么要有 JSON 清洗 + Pydantic？答：模型可能输出 Markdown 围栏或顶层数组，不洗会解析失败
▸ SQLite 和 MySQL 怎么切换？答：DB_DRIVER 环境变量，database.py 有方言转换层（如 INSERT OR REPLACE）
▸ 每日额度/限流在哪实现？答：routes/ai.py 调额度，rate_limit.py 滑动窗口，超限返回 429
